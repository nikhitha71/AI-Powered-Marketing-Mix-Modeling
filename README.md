# AI-Powered Marketing Mix Modeling (MMM) Analyst

## Project Overview
An ongoing Machine Learning project focused on analyzing the impact of different marketing channels on weekly sales using Marketing Mix Modeling (MMM).

The project uses synthetic weekly marketing data to explore the relationship between advertising expenditure, pricing, promotions, seasonality, and sales performance.

## Data Simulation
The synthetic dataset contains 156 weeks of data and includes:

- TV advertising expenditure
- Search advertising expenditure
- Social media advertising expenditure
- Display advertising expenditure
- Email marketing expenditure
- Weekly sales
- Product pricing
- Promotional activity
- Seasonal patterns

## Technologies
- Python
- NumPy
- Pandas
- Databricks
- TensorFlow

## Project Development
The project is being developed in stages:

1. Synthetic marketing data generation.
2. Data preprocessing and exploratory analysis.
3. Marketing Mix Modeling using advertising carryover (Adstock) and diminishing returns (Hill response).
4. Sales prediction and marketing channel contribution analysis.
5. LLM-powered analyst layer for natural-language interpretation of model outputs and tool/function calling.

## Current Status
Ongoing development. The synthetic data generation component is available in this repository. Other modelling and LLM components are being developed.

**Note:** All generated data is synthetic and does not represent actual company or customer data.
